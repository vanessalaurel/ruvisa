# 5. Conclusion and Future Work

This study presented **Ruvisa**, an end-to-end intelligent skincare recommendation system that integrates skin-image analysis, product intelligence, adaptive ranking, and an agentic conversational interface into a single user-facing platform. Taken together, the results show that the overall system can be considered **successful**, because the main project objectives were achieved. The platform was able to transform a user selfie into a structured concern profile, map skincare products into the same concern space, rank products according to concern-level fit, and return recommendations through a natural-language agent that could also retrieve history, compare past analyses, and explain results to the user.

The skin-analysis module produced the most important upstream output for personalization: a usable **seven-dimensional concern vector**. Although the lesion-localization metrics were only moderate, the broader system outcome remained meaningful because the recommendation stage did not require perfect box-level detection. Instead, it required a stable representation of which concerns were most active for the user. In that respect, the skin analyzer met its functional objective. The results also showed a clear asymmetry within the vision pipeline: lesion detection remained the harder task, while severity classification performed strongly once lesion crops were available. This pattern is consistent with the practical limitation of the current work, namely the lack of a larger and more scientifically labeled lesion dataset with stronger class balance, broader skin-tone coverage, and more realistic consumer-photo variation. As a result, the reported precision, recall, and mAP values should be interpreted as engineering performance within the available data conditions rather than as clinical-level diagnostic performance.

The product-intelligence results further strengthened the overall system design. The ingredient-based analyzer provided the most reliable and interpretable source of product evidence, while the review analyzer contributed a useful but sparse experiential signal. The DeBERTa experiments confirmed that **INCI-grounded supervision was more accurate than product-claims supervision**, supporting the decision to treat ingredient evidence as the primary representation for concern-level product understanding. This is an important outcome because it shows that the recommender was grounded more in formulation evidence than in promotional language, which improves both interpretability and consistency.

The ranking module also achieved its intended objective. Cosine similarity provided a clear and interpretable matching mechanism between the user concern vector and the product evidence vector, while the adaptive layer added a lightweight but meaningful form of personalization based on prior outcomes. The observed ranking shifts showed that historical user feedback could materially affect final recommendations without overwhelming the base similarity structure. This means the recommendation system did not operate as a static content matcher alone; it functioned as a hybrid recommender that incorporated both current skin state and user-specific history.

Finally, the agentic layer demonstrated the value of connecting all components into a single conversational workflow. Through FastAPI, LangGraph, Ollama, and the domain-specific tool set, the system was able to retrieve user context, analyze progress over time, recommend products, and respond in natural language. This made Ruvisa more than a collection of separate models. It functioned as an integrated application in which vision outputs, product knowledge, ranking logic, and conversational reasoning were all linked operationally.

Overall, the findings indicate that Ruvisa achieved its primary aim of building a working personalized skincare recommendation platform. The system should not be interpreted as a medical diagnostic tool, and several components still have room for improvement, especially in skin-image detection robustness and external validation. However, the study shows that even with imperfect lesion localization, the full pipeline can still generate coherent, explainable, and practically useful recommendations when the intermediate concern representation is stable.

Future work can extend Ruvisa in several directions. First, the skin-analysis module can be strengthened by training on larger, more scientifically curated lesion datasets and by improving diversity across skin tones, lighting conditions, and consumer image quality. Second, the agentic system can be expanded beyond recommendation alone, for example by comparing **delivery methods** and prioritizing products based on the **shortest distance or fastest fulfillment path** to the user, or by automatically scraping and updating **latest trending skincare products** so that the catalogue remains current. Third, additional perception modules can be added, such as a **skin-tone analyzer** and a more detailed skin-assessment pipeline to support **makeup recommendations** as well as skincare. Fourth, Ruvisa can be extended to recommend **beauty treatments or clinic-based procedures** for users whose concerns may benefit from professional intervention rather than products alone. These directions would move the platform beyond skincare recommendation toward a broader personalized beauty and skin-health decision-support system.
